## 一、产品顶层设计

### 1.1 核心定位

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│           知 研 — AI 时代的思辨陪练平台                      │
│                                                             │
│                    「 AI 问人 」                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**颠覆性洞察**：AI 时代大多是"人问 AI"，而知研是**"AI 问人"**——用 AI 引导人类进行深度思考。

### 1.2 价值主张

| 传统模式 | 知研模式 |
|---------|---------|
| 人问 AI → 获取答案 | AI 问人 → 激发思考 |
| AI 替代人类思考 | AI 帮助人类思辨 |
| 快速获取知识 | 深度打磨观点 |

### 1.3 一句话定位

> **让 AI 帮助人类发掘独特见解，而非替代人类思考。**

### 1.4 产品目标用户

| 用户类型 | 核心特征 | 典型场景 |
|----------|---------|---------|
| **AI 从业者** | 追求深度思考、技术洞察 | 思辨技术路线、验证产品假设 |
| **科研者** | 严谨、爱思辨 | 打磨研究观点、审视论证逻辑 |
| **企业高管** | 决策谨慎、追求真知 | 战略思辨、决策风险评估 |
| **深度思考者** | 主观能动性强 | 观点深化、认知升级 |
| **场景准备者** | 功利性目标明确 | 面试/答辩/演讲准备 |

### 1.5 用户画像系统（跨会话记忆 + 全局注入）

> **核心功能**：记录用户的思辨风格和认知升级轨迹，为**所有 AI 生成内容**提供个性化基础

**关键原则**：用户画像对用户**不可见**，但它是所有 AI 生成节点的"隐形上下文"——包括报告、观点引导、诘问对话、游戏剧本。

**画像数据结构**：

| 维度 | 内容 | 来源 |
|------|------|------|
| **关注领域** | 用户常讨论的话题标签 | 会话历史提取 |
| **思辨风格** | 论证偏好、常用策略 | 行为模式分析 |
| **认知轨迹** | 立场变化、认知升级 | 深度诘问记录 |
| **强项/弱项** | 逻辑强项、思维盲区 | 陷阱检测统计 |

**全局注入机制**：

> **所有涉及 AI 生成的节点，都必须注入用户画像作为 system prompt 的一部分**

**各节点注入映射**：

| 生成节点 | 注入维度 | 注入方式 |
|---------|---------|---------|
| **报告生成** | 关注领域 + 思辨风格 | 调整报告侧重点和深度 |
| **观点引导选项** | 关注领域 + 强项/弱项 | 生成符合认知水平的引导选项 |
| **正常诘问** | 思辨风格 + 历史策略 | 适配用户的论证偏好进行追问 |
| **快速诘问** | 强项/弱点 + 关注领域 | 针对弱点强化，针对强项适度放水 |
| **深度诘问** | 认知轨迹 + 立场变化 | 追踪认知升级，结合历史立场变化 |
| **趣味诘问** | 思辨风格 + 认知轨迹 | 换活泼风格生成对话 |
| **GalGame模式** | 思辨风格 + 认知轨迹 + 强项/弱项 | 生成符合用户特点的剧本 |

### 2.2 正常诘问（默认模式）

**定位**：标准强度，通用场景

| 特征 | 描述 |
|------|------|
| 强度 | 标准（默认档位） |
| 目标 | 一般性思辨 |
| 策略 | 8 种基础策略轮转 |
| 场景 | 通用，无预设 |

### 2.3 快速诘问（功利链）

**定位**：5-30 分钟，达成特定功利目标

| 特征 | 描述 |
|------|------|
| 时间 | 有限（面试5-30分钟） |
| 目标 | 达成特定功利目标 |
| 策略 | 8 种基础策略 + 即时反馈 |
| 强度 | 可调节（温和/标准/犀利） |

### 2.4 深度诘问（真知链）

**定位**：无时间压力，追求认知升级（**强度最高**）

| 特征 | 描述 |
|------|------|
| 时间 | 无限制 |
| 目标 | 追求深度洞察、认知升级 |
| 策略 | 8 种策略 + 高级组合 + 策略联动 |
| 强度 | 最高档（犀利起步，逐步升级） |
| 评估 | 认知升级追踪 |

### 2.5 趣味诘问（活泼风格）

**定位**：在**正常诘问或深度诘问**的基础上，换用活泼风格的系统提示词

| 特征 | 描述 |
|------|------|
| 基础 | 基于正常诘问或深度诘问 |
| 变化 | 更换为活泼风格的提示词（古风/二次元/轻松等） |
| 交互 | 对话式，不弹窗 |
| 目标 | 轻松有趣的思辨体验 |

**趣味诘问示例风格**：

| 风格 | 提示词特征 |
|------|-----------|
| 古风 | 「吾观汝之言，颇有见地，然有一事不解...」 |
| 二次元 | 「哇！小伙伴的想法好棒呢~但是这里有个小问题哦~」 |
| 轻松 | 「哈哈，你这个观点挺有意思的，让我来考考你~」 |

### 2.6 GalGame 模式（独立游戏）

**定位**：LLM 生成独立的 Galgame 风格剧本，通过**弹窗**呈现

| 特征 | 描述 |
|------|------|
| 形式 | 独立游戏窗口 |
| 内容 | LLM 生成情景化剧本 + 剧情选项 |
| 交互 | 弹窗形式，刘看山表情作为情景背景 |
| 目标 | 沉浸式趣味思辨体验 |

**与趣味诘问的区别**：

| 维度 | 趣味诘问 | GalGame 模式 |
|------|---------|-------------|
| **基础** | 对话式诘问换风格 | 独立游戏 |
| **交互** | 对话 | 弹窗 + 剧情选项 |
| **内容** | 同一诘问引擎 | 剧本生成引擎 |
| **刘看山** | 无特定表情 | 动态表情作为情景背景 |
| **触发位置** | 与正常/快速/深度并列 | 独立入口 |

### 2.7 四种诘问模式对比

| 维度 | 正常诘问 | 快速诘问 | 深度诘问 | 趣味诘问 |
|------|---------|---------|---------|-----------|
| **定位** | 默认/通用 | 功利目标 | 真知追求 | 活泼风格 |
| **强度** | 标准 | 温和→犀利 | **最高** | 继承基础模式 |
| **时间** | 无限制 | 5-30分钟 | 无限制 | 无限制 |
| **提示词** | 标准 | 标准 | 标准 | 活泼风格 |
| **界面** | 对话式 | 对话式 | 对话式 | 对话式 |
| **触发** | 默认 | 可选 | 可选 | 可选 |

### 5.2 8 种诘问策略

| 策略 | 名称 | 追问方向 | 难度 |
|------|------|---------|------|
| **M1** | 证据追问 | "你的判断依据是什么？举具体例子" | L1 |
| **M2** | 前提追问 | "你这句话背后的前提假设是什么" | L2 |
| **M3** | 锚定揭露 | "你是否被高赞回答锚定了" | L2 |
| **M4** | 钢铁人反驳 | "对方最强论点你能反驳吗" | L3 |
| **M5** | 系统二激活 | "这是直觉反应还是推算过" | L2 |
| **M6** | 立场反转 | "如果站在对立面怎么说" | L3 |
| **M7** | 元认知 | "你刚才那句话是第一反应吗" | L4 |
| **M8** | 立场崩塌检测 | "你的论证是否自相矛盾" | L4 |

### 5.3 状态机规则

| 规则 | 条件 | 动作 |
|------|------|------|
| **防重复** | 同一策略连续 3 轮 | 切换非相邻策略 |
| **升级** | 近 3 轮平均 >80 字且含证据关键词 | 升级到更难策略 |
| **降级** | 连续 3 轮 <10 字或含"不知道" | 降级到简单策略 |
| **轮转** | 无触发条件 | 按难度序轮转 |

```typescript
interface KnowledgeBaseQuery {
  userInput: string;
  sessionContext: SessionContext;
  knowledgeBases: ('philosophy' | 'debate' | 'logic' | 'domain')[];
}

// 检索结果
interface KnowledgeResult {
  source: 'philosophy' | 'debate' | 'logic' | 'domain';
  content: string;
  relevance: number;
  citation?: string;
}

// 并行检索 + 融合
async function queryKnowledgeBases(
  params: KnowledgeBaseQuery
): Promise<KnowledgeResult[]> {
  const { knowledgeBases, userInput, sessionContext } = params;

  // 1. 并行检索多个知识库
  const results = await Promise.all(
    knowledgeBases.map(base => searchKnowledgeBase(base, userInput))
  );

  // 2. 合并结果
  const merged = results.flat();

  // 3. 去重 + 排序
  const ranked = rankByRelevance(merged);

  return ranked;
}

// 与诘问引擎集成
async function generateQuestion(context: InterrogationContext) {
  // 1. 检索知识库
  const knowledge = await queryKnowledgeBases({
    userInput: context.userAnswer,
    sessionContext: context.session,
    knowledgeBases: ['debate', 'logic']  // 根据用户画像选择
  });

  // 2. 构建增强 prompt
  const enhancedPrompt = `${basePrompt}

[相关知识库内容]
${knowledge.map(k => `[${k.source}]: ${k.content}`).join('\n')}`;

  // 3. 生成诘问
  return await llm.generate({ prompt: enhancedPrompt });
}
```

### 6.4 知识库内容示例

**哲学知识库 - 苏格拉底提问法**：

| 方法 | 描述 | 示例问句 |
|------|------|---------|
| 澄清概念 | 明确术语定义 | "你说的'自由'具体指什么？" |

| 诉诸权威 | 用权威代替论证 | "某专家说..." |
